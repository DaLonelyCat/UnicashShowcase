# Unicat POS & Accounting Showcase Website

Interactive showcase website for Unicat: an offline-first Point of Sale (POS), double-entry accounting ledger, recipe Bill of Materials (BOM) cost engine, and local AI store copilot.

## Features

- **Interactive POS Sandbox**: Test cashier ring-up, live BOM raw ingredient deductions, discount calculation, and simulated 80mm ESC/POS thermal receipt printing.
- **Full Double-Entry Financial Engine**: Explore real-time general journals, profit and loss statements, balance sheets, and cash flow reports.
- **Hardware & Architecture Spec Matrix**: Technical breakdown of offline JSON/CSV persistence, ESC/POS printer drivers (USB, Serial COM, BLE), and local Ollama LLM copilot.
- **High-Resolution Interface Tour**: Desktop host stations and Mobile LAN handheld order-taking chassis mockups.
- **Bilingual & Dual-Theme**: Full English and Indonesian localization with dark and light theme switching.

## Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Deployment Target**: Cloudflare Pages / Vercel / Static Hosting

## Development

Install dependencies:
```bash
npm install
```

Start the local development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```
